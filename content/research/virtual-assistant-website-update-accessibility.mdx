# Website Updates by Virtual Assistants: Accessibility Risk Research

Website administration is not only a publishing task. A changed heading, link, image, or form can alter how people navigate and understand a page.

## Content edits can change access

WCAG 2.2 groups accessibility around perceivable, operable, understandable, and robust experiences [1]. W3C explains that accessibility benefits people with permanent, temporary, and situational limitations [2]. A virtual assistant handling routine text changes should therefore know when a change stays editorial and when it affects structure.

## Separate low-risk edits from structural edits

| Change | Initial question | Escalate when |
| --- | --- | --- |
| Text | Does the heading still describe the section? | Meaning or hierarchy changes |
| Link | Is the destination and label clear? | A critical path changes |
| Image | Is alternative text accurate? | The image carries new meaning |
| Layout | Can keyboard and zoom users complete the path? | Markup or focus behavior changes |

Use the [accessibility research page](/research/virtual-assistant-digital-accessibility-review) as a comparison point, not as a substitute for testing the affected route. Security and privacy controls should also be considered when the update touches a form or account area [6][7]. The [service overview](/services) should describe scope without implying certification.

## Methodology and limitations

This brief compares W3C accessibility guidance, browser documentation, usability heuristics, search guidance, and security and advertising references checked on 2026-08-11. It does not certify conformance or predict conversion.

## Key takeaways

- Review structure, not just spelling.
- Test the user path changed by the edit.
- Assign one owner who can reverse a harmful change.
