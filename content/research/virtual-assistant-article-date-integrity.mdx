# Article Publication Date Integrity: A Virtual Assistant Research Brief

Published September 1, 2026.

Date integrity matters because readers, search systems, feeds, and internal operations may each consume a different representation of the same publication event.
Related operating context appears in the [daily article status guide](/blog/virtual-assistant-daily-article-status) and the [article source traceability guide](/blog/virtual-assistant-article-source-traceability).

## Treat publication as a recorded event

Define `datePublished` as the organization's original public release date and retain the timezone convention used to assign it. Build timestamps and file modification times describe technical activity, not necessarily publication.

## Align human and machine representations

The visible date, HTML time value, Article structured data, and content inventory should refer to the same calendar event. Schema.org defines `datePublished`, while search documentation recommends accurate, consistent dates that are prominent to users.

## Preserve modification history separately

Use `dateModified` for material updates according to a written policy. A correction should not silently erase the original publication date. Retained revision evidence allows reviewers to distinguish a refreshed article from a newly released one.

## Test timezone behavior in output

Parsing a date-only value through local time can display the prior or next day in another environment. An automated check should inspect the built page and structured data under the deployment's actual date handling, not assume the source string is enough.

## Methodology and limitations

This brief synthesizes public structured-data, web-platform, archival, and metadata guidance. It does not set legal record-retention requirements or determine when an editorial update is substantial enough to change modification metadata.

## Key takeaways

- Define the publication event and timezone before entering metadata.
- Check the visible label and structured value in rendered output.
- Retain the original date while recording material modifications separately.
