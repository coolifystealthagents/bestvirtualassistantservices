# Virtual Assistant Client Feedback Analysis: A Research Brief

Feedback analysis is useful when the path from original comment to coded theme to decision remains visible.

## Preserve the source context

Record channel, date, audience, prompt, consent or policy basis, and any response status. The [feedback controls brief](/research/virtual-assistant-customer-feedback-controls) adds handling boundaries.

## Make themes testable

Define coding rules, code a sample, compare disagreements, and report counts with the denominator. The [survey operations brief](/research/virtual-assistant-survey-operations-controls) covers collection quality.

| Pass | Question | Evidence |
| --- | --- | --- |
| Context | What was actually said? | Source record |
| Coding | Does the rule fit? | Codebook and sample |
| Decision | What action is supported? | Owner rationale |

## Methodology and limitations

Ten official sources on privacy, accessibility, security, records, and digital work were reviewed on 2026-08-10. Feedback is directional unless the collection and sampling design support broader inference.

## Key takeaways

- Preserve the original context before summarizing.
- Publish coding rules and denominators.
- Treat a theme as a signal until an owner validates the action.

## FAQs

### Can an assistant decide the top customer problem?

They can summarize coded evidence. The responsible owner should decide whether it represents the highest priority.

### How should sensitive comments be handled?

Limit access, redact unnecessary detail, and follow the approved retention and privacy process.
