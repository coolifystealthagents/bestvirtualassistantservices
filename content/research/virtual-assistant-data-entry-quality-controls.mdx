# Virtual Assistant Data Entry Quality Controls: A Research Brief

Reliable data entry starts with a field definition and ends with a correction trail. Speed without validation simply moves errors downstream.

## Establish field rules

Document required fields, formats, source of truth, allowed blanks, and sensitivity. The [CRM hygiene brief](/research/virtual-assistant-crm-data-hygiene) shows how to handle duplicate and stale records.

## Validate before handoff

Use required-field checks, format checks, duplicate detection, and a sample against the source. The [quality scorecard](/research/virtual-assistant-quality-scorecard) can hold the weekly trend.

| Check | Evidence | Escalate when |
| --- | --- | --- |
| Completeness | Missing-field report | Required value absent |
| Accuracy | Source sample | Value differs |
| Uniqueness | Duplicate query | Match needs judgment |
| Traceability | Correction log | Source cannot be located |

## Methodology and limitations

This brief synthesizes ten official sources reviewed on 2026-08-10. It describes workflow controls and does not establish a specific accuracy threshold for every database.

## Key takeaways

- Define fields before assigning entry work.
- Sample completed records against the authoritative source.
- Preserve corrections so recurring errors can be fixed at the process level.

## FAQs

### Should every record be manually checked?

Use risk-based sampling, with full review for sensitive or high-impact records.

### What belongs in a correction log?

Record the field, original value, corrected value, source, date, and reviewer.
