# How often does a single-role VA create an unplanned coverage gap?

## Research question and scope

This is a proposed research protocol, not a report of completed findings. It asks how often a single-role virtual assistant arrangement creates an unplanned coverage gap and how long the gap lasts. The result would help a buyer judge whether a backup plan is adequate. A control that depends on memory is not yet a control.

The protocol does not measure the assistant's reliability. It measures the exposure created by the role design. The sponsor should name the coverage decision the result could inform. Keep the evidence with the record rather than in a separate log.

## Population and unit of analysis

Define the population as all workdays in a stated period for a role with one primary assistant. The unit is one workday, with the primary's availability, the backup's availability, and the must-continue tasks recorded. Days with no must-continue work should be counted separately. Keep the boundary visible in the place where the work is assigned.

Record the reason for each gap, such as planned leave, illness, a system outage, or a task that the backup could not perform. The reason matters because a planned gap and an unplanned gap need different controls. Separate what was observed from what was assumed. Keep the boundary visible in the place where the work is assigned.

## Definitions and measures

Define a coverage gap as a workday when a must-continue task was not completed by the promised time because the primary was unavailable. Define gap duration as the working time until the task was completed or the deadline passed. Define exposure as the number of clients or processes affected. Use the same format for every handover so the next reader can scan it.

Report the gap rate, the duration, and the exposure separately. A single long gap may matter more than several short ones. The measures should let the reader judge the consequence, not just the frequency. Update the template when the same question appears twice.

## Evidence standard

Link each gap to the task, the deadline, the primary's availability record, and the backup's action. A gap that is only remembered in a conversation is weak evidence. Use the task system and the calendar where possible. Write the deadline as a date and a local time.

Where the cause is ambiguous, record the facts and the interpretation separately. A gap may be caused by a late request rather than an unavailable assistant. The study should preserve that distinction. Review the first few notes together before the process expands.

## Sampling and collection

Use a census of the period if the role is small. If several roles are compared, stratify by task type and backup arrangement. Select the roles before reviewing gaps and keep a log of exclusions. Keep the evidence with the record rather than in a separate log.

Pilot the data collection on a few days and compare the reviewers' classifications. Clarify what counts as a must-continue task and how a task completed late is treated. Record the rules. Record the observation time so the next reviewer can tell when the evidence was checked.

## Analysis and reporting

Report the gap rate by cause and by task type, with the number of workdays in the denominator. Show the duration and exposure beside the rate. A low gap rate with one severe gap may still be a serious risk. Record the exception and the person who approved it.

Describe the backup arrangement for each role and whether it was used. A plan that exists but is never tested is not evidence of coverage. The report should name the practical questions for the buyer. Keep the evidence with the record rather than in a separate log.

## Limits and sources of error

The study may miss gaps that were absorbed quietly by a colleague and never recorded. The role's task list may also change during the period. State the population and the period clearly. If the source is unclear, route the question instead of guessing.

The person recording the gap may be the same person responsible for the coverage plan. Use a second reviewer for the classification if possible. The report should name that limitation. Keep the boundary visible in the place where the work is assigned.

## Review cadence

Repeat the review after a change to the backup plan or the role's task list. Compare the same gap definitions and the same period length. A lower gap rate is useful only if the must-continue work was still completed. Keep the original note beside the corrected version.

Assign the follow-up to the buyer's operations owner and set a date. The protocol should produce a specific decision about the backup arrangement or the task list. Separate what was observed from what was assumed. A control that depends on memory is not yet a control.
