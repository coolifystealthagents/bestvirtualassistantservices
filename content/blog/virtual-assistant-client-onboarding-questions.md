# Virtual Assistant Client Onboarding Questions

Good onboarding questions reveal how work is requested, approved, stored, and handed back. They should be purposeful, grouped by decision, and easy for a client to answer.

## Virtual Assistant Client Onboarding Questions: begin with outcomes

Ask which recurring outcomes matter, what a finished item looks like, and which work should remain with the owner. This establishes boundaries before tools are discussed.

## Clarify communication

Ask where requests arrive, how urgent items are identified, and when a clarification is expected. Never infer permission to use a channel from its convenience.

## Document authority

Identify who approves changes, sends commitments, and resolves exceptions. The [onboarding controls guide](/blog/virtual-assistant-client-onboarding-controls) supports boundaries, while the [intake data guide](/blog/virtual-assistant-client-intake-data-controls) supports record handling.

## Keep questions proportionate

Start with what is necessary for the first work item and defer useful but nonessential detail. A short unanswered list is better than a large form no one can maintain.

## Handle information carefully

Ask for access through approved channels and avoid placing credentials in notes. Review [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) when setting the handoff.
