# Virtual assistant compliance evidence folders



## How to manage Virtual assistant compliance evidence folders

Name the control question, period, owner, source system, collection date, and audience. Mark missing, superseded, and unavailable records separately.

## Role boundary for Virtual assistant compliance evidence folders

A folder can organize evidence but cannot prove compliance by itself; the responsible owner decides sufficiency.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
