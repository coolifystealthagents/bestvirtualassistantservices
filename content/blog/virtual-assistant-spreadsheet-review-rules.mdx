# Virtual Assistant Spreadsheet Review Rules

For spreadsheet review rules, begin with the record that makes the next decision possible, then keep the owner and stopping point visible.

## Virtual Assistant Spreadsheet Review Rules: Read the workbook’s purpose first

Before checking cells, identify who uses the spreadsheet, what decision it supports, and which tab or range is authoritative. A technically tidy workbook can still answer the wrong question. Write down the reporting period and expected grain of each table.

## Check structure before arithmetic

Look for mixed data types, duplicate headers, hidden rows, merged cells, blank identifiers, and inconsistent date formats. Structural defects often explain a surprising total more directly than a complicated formula does. Review a representative sample before scanning every row.

## Trace formulas and inputs

Test formulas at the edges: first row, last row, a blank input, a zero, and a known exception. Check whether copied formulas shift references correctly. Keep source values distinct from calculated results so a reviewer can see what changed.

## Make corrections reversible

Record the cell or range, issue found, correction, and source. Use comments or a change log rather than silently replacing a disputed value. When the source is missing, flag the gap and leave the value unresolved.

## Leave the workbook understandable

Use clear headers, freeze the useful context, and document unusual assumptions near the table. The [Microsoft table guidance](https://support.microsoft.com/en-us/office/create-and-format-a-table-0fce08c4-79a5-4f4e-8d1b-6b8c2d6a5b31) offers practical structure for making tabular data easier to sort and inspect.


## Keep the decision visible

For this topic, preserve the source and route uncertainty to the named owner.
