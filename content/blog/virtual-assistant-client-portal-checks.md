# Virtual Assistant Client Portal Checks

Portal checks should confirm that the right record is present, current, and visible to the intended audience. They should not become an excuse to browse unrelated client material.

## Virtual Assistant Client Portal Checks: define the expected record

List the client, record type, required fields, current period, and source of truth. A check is only meaningful when the expected result is explicit.

## Verify before changing

Compare the portal record with the approved source and note differences before editing. Preserve a clear reason for any correction.

## Check visibility separately

Confirm that the record is shared with the intended role and not a broader audience. The [portal administration guide](/blog/virtual-assistant-client-portal-administration) supports routine checks, while the [document control guide](/blog/virtual-assistant-document-control) supports revisions.

## Escalate access questions

Stop when a permission is unclear or the request would expose another client’s information. Ask the named owner rather than experimenting with access.

## Keep audit details minimal

Record the check result and source link without duplicating confidential contents. [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) offers useful access principles.
