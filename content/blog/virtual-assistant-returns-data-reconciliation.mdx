# Virtual Assistant Returns Data Reconciliation

A method for comparing returns records, order details, and customer notes before an owner decides the next action.

## Virtual Assistant Returns Data Reconciliation: Compare records by a stable reference

Use the order or case number as the primary key, then compare item, date, reason, status, and evidence. Keep unmatched records in a separate queue instead of forcing a match. Define the period and systems included so the reconciliation has a clear boundary.

## Flag exceptions with evidence

A virtual assistant can identify duplicates, missing tracking, inconsistent statuses, and overdue next actions. The owner decides refunds, policy exceptions, and disputes. Link to the customer support queue guide when customer communication and operational records need to stay aligned.

## Report the cause of differences

Summarize counts by matched, missing, duplicate, and owner review. Note whether the issue came from timing, a system field, or an incorrect entry. NIST small-business guidance is relevant when order and customer records are joined in a working file: [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber)

## Frequently asked questions

### What should the owner provide first?

Provide the source of truth, approved examples, the expected output, the reviewer, and a clear rule for exceptions.

### What should remain with the owner?

Keep approvals, policy interpretation, sensitive decisions, and irreversible changes with the responsible owner.
