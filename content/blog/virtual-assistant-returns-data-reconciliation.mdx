# Virtual Assistant Returns Data Reconciliation

Virtual Assistant Returns Data Reconciliation explains how to delegate returns data reconciliation while keeping the owner’s decisions visible.

## Virtual Assistant Returns Data Reconciliation: start with the source

returns data reconciliation starts with order, item, quantity, return state, and transaction. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant Returns Data Reconciliation: notice the real risks

returns data reconciliation has a different risk profile: duplicate credits, split records, and refunds that cannot be explained. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant Returns Data Reconciliation: write a bounded request

Write a bounded request for returns data reconciliation around order, item, quantity, return state, and transaction. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant Returns Data Reconciliation: preserve disagreements

If returns data reconciliation produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant Returns Data Reconciliation: keep authority clear

For returns data reconciliation, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant Returns Data Reconciliation: show the exception

Build a normal example and a pause example from order, item, quantity, return state, and transaction. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant Returns Data Reconciliation: make completion observable

Close returns data reconciliation with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant Returns Data Reconciliation: protect the record

Protect returns data reconciliation with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant Returns Data Reconciliation: ask before closing

Before returns data reconciliation changes hands, check order, item, quantity, return state, and transaction and leave duplicate credits, split records, and refunds that cannot be explained visible where they affect the decision.
