# Virtual assistant work sample evaluation

Use a bounded sample with source material, expected output, time window, privacy limits, and escalation condition. Score source use, accuracy, organization, judgment boundary, and uncertainty handling.

## Applying virtual assistant work sample evaluation

A work sample should resemble the role without exposing unnecessary personal or confidential data. Define the source material, time window, expected output, allowed tools, scoring criteria, and stop condition. Evaluate reasoning and uncertainty handling, not just polished formatting produced under artificial conditions.

## Role boundary and review

The reviewer can score source use, accuracy, organization, and escalation against the same rubric for each candidate. The hiring owner decides whether a gap is coachable or disqualifying and keeps candidate evidence confidential. Record the sample version and accommodations so scores remain comparable without claiming predictive certainty.

Use the [services library](/services) to define the task lane, while the [provider vetting guide](/provider-vetting) frames a fair review conversation. [NIST guidance](https://www.nist.gov/itl/smallbusinesscyber) is a useful general safeguard reference for sample data.

### Sample record

Keep the sample version, permitted data, rubric, accommodations, reviewer notes, decision, and retention limit.
