# Virtual Assistant Event Registration Support

How to organize event registrations, confirmations, and exceptions while keeping attendee data accurate and appropriately handled.

## Virtual Assistant Event Registration Support: Define the registration record

Choose the source of truth and required fields before registrations arrive. Include attendee name, contact channel, event, status, dietary or accessibility request when relevant, and consent or communication preference. Explain which fields are optional and who handles sensitive requests.

## Use status and exception queues

A virtual assistant can reconcile lists, send approved confirmations, and flag duplicates or incomplete records. The event owner should approve unusual access requests, refunds, substitutions, and changes to capacity. The customer onboarding checklist shows how a clear missing-information queue improves handoffs.

## Protect the attendee list

Limit exports, store files in the approved location, and remove temporary copies after the event. Reconcile attendance and no-shows without exposing unnecessary details. NIST small-business guidance provides useful principles for account and data protection: [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber)

## Frequently asked questions

### What should the owner provide first?

Provide the source of truth, approved examples, the expected output, the reviewer, and a clear rule for exceptions.

### What should remain with the owner?

Keep approvals, policy interpretation, sensitive decisions, and irreversible changes with the responsible owner.
