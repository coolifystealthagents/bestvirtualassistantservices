# Virtual assistant website content update requests



## How to manage Virtual assistant website content update requests

Name the URL, current text, replacement text, asset, reviewer, preview requirement, and publish approval. A scoped edit is not permission to change navigation or tracking.

## Role boundary for Virtual assistant website content update requests

Keep requested, reviewed, and published versions distinct and include accessibility review in the handoff.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [W3C WCAG standards](https://www.w3.org/WAI/standards-guidelines/wcag/).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
