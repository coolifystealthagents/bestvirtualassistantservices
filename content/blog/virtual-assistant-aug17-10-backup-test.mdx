# Virtual assistant backup coverage tests

List recurring queues, critical deadlines, source locations, approval boundaries, and handoff evidence. Test the alternate with an ordinary task, exception, and incomplete request.

## Applying virtual assistant backup coverage tests

Backup coverage is a capability claim that needs a realistic demonstration. Give the alternate a normal task, a missing-input case, and an exception, then check whether they can find the current source and know when to stop. A name on a roster is not evidence of usable coverage.

## Role boundary and review

The assistant can prepare test materials and record where the alternate needed help. The owner decides whether to narrow the queue, add supervised practice, or accept a coverage gap. Store the result with the date, task version, reviewer, and follow-up rather than treating the test as permanent proof.

Use the [services library](/services) to define the work a backup must cover, while the [provider vetting guide](/provider-vetting) frames continuity questions. [NIST guidance](https://www.nist.gov/itl/smallbusinesscyber) is useful when backup access is involved.

### Coverage test record

Keep task version, test cases, observed assistance, reviewer, coverage decision, and follow-up date.
