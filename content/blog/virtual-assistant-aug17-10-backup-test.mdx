# Virtual assistant backup coverage tests



## How to manage Virtual assistant backup coverage tests

Remove the primary operator from a normal task and test source discovery, status comprehension, safe completion, and escalation.

## Role boundary for Virtual assistant backup coverage tests

Record delays from missing access or unclear instructions, then update the handoff rather than asking the backup to improvise policy.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [NIST contingency planning guide](https://csrc.nist.gov/publications/detail/sp/800-34/rev-1/final).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
