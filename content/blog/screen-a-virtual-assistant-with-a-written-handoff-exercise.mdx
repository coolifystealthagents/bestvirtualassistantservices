# Screen a virtual assistant with a written handoff exercise

## How to approach: Screen a virtual assistant with a written handoff exercise

A written handoff exercise shows whether a candidate can leave work another person can continue. The prompt should include a task, a source, and a next deadline. The reviewer should score the note, not the candidate's confidence. Keep the boundary visible in the place where the work is assigned.

Keep the exercise short enough to finish in under an hour. A long exercise measures stamina, not the skill you need. Name the owner in the same line as the action. Keep the boundary visible in the place where the work is assigned.

## Build a safe fixture

Use invented names, addresses, and account numbers. Provide a read-only folder or a test document. Remove any live access and personal data. Keep the evidence with the record rather than in a separate log.

Write the brief with one routine task, one exception, and one question that requires a decision. The mix shows whether the candidate recognizes the boundary. A short note with four fields is easier to use than a long narrative. Write the deadline as a date and a local time.

## Score the note

Use a scorecard with accuracy, source, next action, and boundary. Accuracy covers the facts. Source covers whether the note points to the evidence. A short note with four fields is easier to use than a long narrative.

Give credit for a clear question when the brief is ambiguous. Penalize a confident guess more than a slow handoff. Name the owner in the same line as the action. Record the date and the source so the next reviewer can repeat the check.

## Compare candidates on the same evidence

Review the notes with the same reviewer and the same rubric. Record one example for each score. Do not let the interview overwrite a weak sample. Ask whether a new reviewer could act on the record without a conversation.

Ask each candidate to explain one decision. Listen for the source and the consequence, not just the outcome. A control that depends on memory is not yet a control. Keep the original note beside the corrected version.

## Review the exercise after the hire

Compare the exercise score with the first-month work. Update the rubric if the exercise misses a real gap. A screen that never changes is not learning. Keep the evidence with the record rather than in a separate log.
