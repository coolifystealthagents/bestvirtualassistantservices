# Virtual assistant recurring-work backlogs

Track task, recurrence, last completion, next due date, owner, source, and exception. This guide is for buyers and operators who need a clear role boundary before assigning work to a Philippines-based virtual assistant.

## Virtual assistant recurring-work backlogs starts with a clear brief

Separate routine work from one-off requests and set an aging rule for blocked items. Put the expected output, source of truth, review owner, and stop condition in the brief. If the request changes, record the change instead of quietly expanding the role.

## Keep preparation separate from decisions

The assistant keeps the queue current. The owner sets priorities when demand exceeds capacity. The virtual assistant can gather context, normalize records, flag missing evidence, and prepare a review queue. The accountable owner keeps decisions involving commitments, sensitive information, public statements, or irreversible changes.

## Make the handoff easy to inspect

At handoff, include completed work, unresolved questions, source links, next owner, and review date. For a security baseline, consult the [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber).

## Frequently asked questions

### What should the owner define first?

Define the intended outcome, source of truth, reviewer, and approval boundary before assigning the first task.

### When should the virtual assistant escalate?

Escalate when information is missing, the request leaves the brief, a sensitive decision is involved, or the expected result cannot be checked.

### What makes a handoff ready?

A new reviewer can understand status, evidence, open questions, and next action without reconstructing a private conversation.
