# Virtual Assistant Podcast Production Workflow

Published August 31, 2026.

A podcast assistant can coordinate production when editorial judgment and final publication remain with the owner.

## Virtual Assistant Podcast Production Workflow: build the episode record

Track the guest, topic, consent, assets, recording date, editor status, review owner, and release date. The [service role library](/services) helps separate coordination from editorial authority.

## Coordinate assets and deadlines

Use approved templates to request biographies, headshots, links, and release forms. Flag missing items early and never imply that a draft release date is confirmed.

## Run the publication check

Confirm titles, descriptions, links, captions, and approvals before scheduling. Apply basic account protection using the [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber).

## Complete the release handoff

Record the published URLs, timestamp, final assets, and any corrections awaiting review. Use the [provider vetting checklist](/provider-vetting) when assessing content operations support.

## Frequently asked questions

### What should the assistant document?

Document the source, action, status, owner, due date, and any exception that needs review.

### When should work stop?

Stop when evidence is missing, instructions conflict, access is inappropriate, or an owner-only decision is required.
