# Virtual assistant SOP change logs



## How to manage Virtual assistant SOP change logs

A change log should name the prior version, new instruction, reason, approver, effective date, and affected tool.

## Role boundary for Virtual assistant SOP change logs

Mark superseded copies and route changes to the process owner when they alter authority or customer commitments.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [NARA records management guidance](https://www.archives.gov/records-mgmt).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
