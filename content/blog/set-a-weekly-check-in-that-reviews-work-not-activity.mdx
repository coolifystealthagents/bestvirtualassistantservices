# Set a weekly check-in that reviews work, not activity

## How to approach: Set a weekly check-in that reviews work, not activity

A weekly check-in should review the work the assistant produced, not the hours spent. Choose a small sample, the open questions, and the next decision. A check-in that reads a task list becomes a status report. Use the same format for every handover so the next reader can scan it.

Keep the meeting short and prepare the sample in advance. The manager should see the work before the meeting, not during it. Record the date and the source so the next reviewer can repeat the check. Write the deadline as a date and a local time.

## Choose the sample

Pick one routine task, one exception, and one task the client challenged. The mix shows whether the standard holds under pressure. A sample of only easy tasks hides the problem. Use the same format for every handover so the next reader can scan it.

Send the sample with a short note on what to look for. The assistant should know the criteria before the meeting. Test the rule on one real task before applying it to the queue. Name the owner in the same line as the action.

## Review the open questions

List the questions the assistant could not answer with the brief. A repeated question is a brief problem, not a performance problem. Update the brief or the source. Name the owner in the same line as the action.

Record the owner and the date for each open question. A question without an owner will return. Separate what was observed from what was assumed. Keep the boundary visible in the place where the work is assigned.

## Set the next decision

End the check-in with one decision: continue, adjust, or escalate. Record the decision and the next review date. A check-in without a decision is a conversation. Separate what was observed from what was assumed.

Keep the decision with the work sample. A later review may need to see what was agreed. Use the same format for every handover so the next reader can scan it. Name the owner in the same line as the action.

## Review the check-in quarterly

Ask the assistant and the manager whether the check-in helped. A check-in that produces no change is not working. Change the sample or the cadence. Review the first few notes together before the process expands.
