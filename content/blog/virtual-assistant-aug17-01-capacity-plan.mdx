# Virtual assistant capacity planning



## How to manage Virtual assistant capacity planning

Count calendar blocks, reconciled records, and drafted replies as separate units because each consumes different checking time.

## Role boundary for Virtual assistant capacity planning

The assistant can surface an aging queue, but the owner decides whether to defer, reassign, or change the promise.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
