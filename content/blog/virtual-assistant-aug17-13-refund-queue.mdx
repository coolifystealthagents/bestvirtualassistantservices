# Virtual assistant refund queue handling

Preserve request, transaction reference, reason, evidence, policy path, and owner. Reconcile identity and source records before the authorized owner decides eligibility, amount, or communication.

## Applying virtual assistant refund queue handling

Refund triage should make the policy path visible before a transaction is changed. Match the request to the source order, preserve the reason and evidence, and separate duplicate, incomplete, and clearly eligible cases. The queue should show what is waiting for a policy owner rather than hiding it in a generic status.

## Role boundary and review

The assistant can reconcile references, identify missing proof, and prepare the case. The authorized owner decides eligibility, amount, and customer communication, especially when policy language conflicts with the record. Retain the decision reason and source version for any case that becomes a precedent.

### Refund case record

Keep transaction reference, policy version, evidence, reason code, authorized decision, amount if applicable, and communication status.
