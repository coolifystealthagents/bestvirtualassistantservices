# Virtual assistant refund queue handling



## How to manage Virtual assistant refund queue handling

Show account reference, request date, reason, policy source, evidence status, reviewer, and next action. Separate duplicate, missing-proof, policy-conflict, and fraud concerns.

## Role boundary for Virtual assistant refund queue handling

The assistant can normalize the queue; an authorized owner decides eligibility and amount.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [CFPB compliance resources](https://www.consumerfinance.gov/compliance/compliance-resources/).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
