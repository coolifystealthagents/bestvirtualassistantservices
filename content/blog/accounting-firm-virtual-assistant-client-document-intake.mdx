# Design Virtual Assistant Support for Accounting Client Document Intake

Published 2026-10-05.

Accounting document intake is a chain-of-custody and completeness problem before it becomes accounting work. A virtual assistant can organize secure requests, classify received files, and chase missing items, while accounting professionals retain interpretation, adjustments, advice, and filing decisions.

## Design Virtual Assistant Support for Accounting Client Document Intake: Build requests from an engagement-owned list

Tie every requested item to the client, period, engagement, and responsible professional. Generic prior-year lists require owner review.

## Use a secure intake channel

Define identity checks, upload locations, notification handling, and prohibited email attachments. Never ask clients to send passwords.

## Preserve the received artifact

Keep source files, received times, submitter context, and duplicate relationships. Renaming for organization must not destroy provenance.

## Distinguish present from acceptable

An assistant can confirm that a file opens and resembles the requested category; the accountant decides sufficiency and accounting treatment.

## Escalate sensitive mismatches

Wrong-client data, unexpected personal information, suspicious files, and account-number conflicts follow a documented security route.

## Hand off a reconciled index

The professional receives an itemized package showing present, missing, superseded, unreadable, and awaiting-review records with direct links.

## A realistic boundary test

A client uploads two payroll reports with the same filename and different totals. The assistant preserves both originals, records their receipt times, and flags the conflict against the requested period. Neither file is renamed as 'final,' and no total is selected. The engagement owner identifies the controlling report and documents the reason. The assistant updates the index and missing-item status, leaving the professional judgment visible rather than hiding it in folder cleanup.

## Questions to put in the provider scorecard

### 1. Who owns each engagement request list?

Have the provider answer 'Who owns each engagement request list?' inside the actual accounting client document intake system. The walkthrough should use the records and controls described under 'Build requests from an engagement-owned list', show who may act, and preserve the point where the assistant must stop or escalate.

### 2. Which channel is approved for uploads?

Test 'Which channel is approved for uploads?' with one ordinary item and one awkward exception from the accounting client document intake queue. Compare both outcomes with the procedure in 'Use a secure intake channel', including the source used, the decision owner, and the evidence left for review.

### 3. How is provenance retained after naming changes?

Do not accept a policy recital for 'How is provenance retained after naming changes?' Ask to see a privacy-safe example from the accounting client document intake workflow, then trace the relevant authority and the recovery path back to 'Preserve the received artifact'. Record any part that the provider cannot demonstrate.

### 4. Who decides whether a document is sufficient?

For 'Who decides whether a document is sufficient?' require a named person, a controlling record, and an observable completion test. Use 'Distinguish present from acceptable' as the boundary: the assistant may perform the administrative step, while the identified owner handles the judgment or exception.

### 5. What triggers the security route?

Rehearse 'What triggers the security route?' during the paid pilot. Introduce a missing field or failed handoff that matters to accounting client document intake, and check whether the process in 'Escalate sensitive mismatches' detects it, assigns correction, and tells the buyer what remains open.

### 6. What states appear in the professional handoff?

Close the scorecard item 'What states appear in the professional handoff?' only with retained evidence from the accounting client document intake test. The acceptance note should point to 'Hand off a reconciled index', state the approved scope and exclusions, and name the event that would send the work back for review.
