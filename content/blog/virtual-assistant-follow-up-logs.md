# Virtual Assistant Follow-Up Logs

Follow-up logs prevent a useful conversation from dissolving into memory. They work best when each entry names the commitment, owner, evidence, and next check rather than repeating the whole conversation.

## Virtual Assistant Follow-Up Logs: write the commitment

Use the smallest accurate statement of what was agreed. Distinguish a request, a proposal, and an accepted commitment so the log does not create authority where none exists.

## Assign one owner

One entry may have contributors, but it should have one accountable next owner. If ownership is undecided, record that decision as the next follow-up.

## Add a meaningful date

Use the agreed due date or a review date, and identify the source. Avoid inventing urgency simply because a message is old.

## Close with evidence

Mark an entry complete only when the source shows the action happened. The [meeting follow-up guide](/blog/virtual-assistant-meeting-follow-up-workflow) supports capture, and the [status reporting guide](/blog/virtual-assistant-project-status-reporting) supports escalation.

## Keep logs appropriate

Link to sensitive details rather than duplicating them. Consult [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) when setting access and retention.
