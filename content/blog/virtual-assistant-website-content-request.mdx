# Virtual Assistant Website Content Request Checklist

Virtual Assistant Website Content Request Checklist explains how to delegate website content request while keeping the owner’s decisions visible.

## Virtual Assistant Website Content Request Checklist: start with the source

website content request starts with audience, objective, source, format, due date, and approver. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant Website Content Request Checklist: notice the real risks

website content request has a different risk profile: requests that expand midstream and pages published without a review point. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant Website Content Request Checklist: write a bounded request

Write a bounded request for website content request around audience, objective, source, format, due date, and approver. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant Website Content Request Checklist: preserve disagreements

If website content request produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant Website Content Request Checklist: keep authority clear

For website content request, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant Website Content Request Checklist: show the exception

Build a normal example and a pause example from audience, objective, source, format, due date, and approver. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant Website Content Request Checklist: make completion observable

Close website content request with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant Website Content Request Checklist: protect the record

Protect website content request with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant Website Content Request Checklist: ask before closing

Before website content request changes hands, check audience, objective, source, format, due date, and approver and leave requests that expand midstream and pages published without a review point visible where they affect the decision.
