# Virtual Assistant Website Content Request Checklist

A clear intake checklist for website updates that helps a virtual assistant prepare changes without publishing unapproved claims or broken links.

## Virtual Assistant Website Content Request Checklist: Describe the requested outcome

Include the page, requested change, source text, audience, deadline, approval owner, and any required link or image. Identify whether the request is a correction, an update, or a new claim. A source link or approved copy should accompany anything factual or customer-facing.

## Prepare changes for review

A virtual assistant can collect inputs, format a draft, check links, and list unresolved questions. The owner approves claims, service descriptions, legal language, and publication. The document review guide can be adapted for page-level review.

## Keep a before-and-after record

Save the request, approved version, reviewer, and date. Check the page on desktop and mobile after an approved change, then record any issue for follow-up. NIST small-business guidance is relevant when a content request includes credentials, customer records, or restricted files: [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber)

## Frequently asked questions

### What should the owner provide first?

Provide the source of truth, approved examples, the expected output, the reviewer, and a clear rule for exceptions.

### What should remain with the owner?

Keep approvals, policy interpretation, sensitive decisions, and irreversible changes with the responsible owner.
