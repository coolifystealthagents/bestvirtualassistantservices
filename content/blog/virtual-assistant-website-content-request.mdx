# Virtual Assistant Website Content Requests

For website content requests, begin with the record that makes the next decision possible, then keep the owner and stopping point visible.

## Virtual Assistant Website Content Requests: Define the page’s job

A content request should identify the audience, page purpose, desired action, owner, source material, and deadline. If the request is for a change to an existing page, include the current URL and the reason for the change. A precise brief reduces rounds of interpretation.

## Give the writer usable source material

Provide approved facts, product names, customer language, required disclaimers, and examples of what must remain unchanged. Mark claims that need confirmation. Source links are more useful than a paragraph copied into an email because they preserve context.

## Write for the person scanning

Ask for a direct heading, short paragraphs, descriptive links, and a clear next step. The request should mention the reading context: mobile, comparison, support, or first visit. Good structure helps people find the answer before they decide whether to continue.

## Include accessibility from the start

Describe image purpose, heading hierarchy, link meaning, form labels, and keyboard or contrast considerations in the brief. Accessibility is not a final polish layer. The [W3C Web Content Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/) provide an authoritative baseline for planning inclusive content.

## Define acceptance in observable terms

State what must be true when the page is ready: facts approved, links checked, required sections present, and the named owner satisfied. Keep optional improvements separate from the launch requirement. This makes a content request easier to review without turning it into a vague debate.


## Keep the decision visible

For this topic, preserve the source and route uncertainty to the named owner. Reference: [W3C Web Content Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/).
