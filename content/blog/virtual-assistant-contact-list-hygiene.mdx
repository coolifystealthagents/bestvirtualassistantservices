# Virtual Assistant Contact List Hygiene

Virtual Assistant Contact List Hygiene explains how to delegate contact list hygiene while keeping the owner’s decisions visible.

## Virtual Assistant Contact List Hygiene: start with the source

contact list hygiene starts with identity, source date, duplicate status, and consent. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant Contact List Hygiene: notice the real risks

contact list hygiene has a different risk profile: merged people, stale preferences, and unsafe exports. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant Contact List Hygiene: write a bounded request

Write a bounded request for contact list hygiene around identity, source date, duplicate status, and consent. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant Contact List Hygiene: preserve disagreements

If contact list hygiene produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant Contact List Hygiene: keep authority clear

For contact list hygiene, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant Contact List Hygiene: show the exception

Build a normal example and a pause example from identity, source date, duplicate status, and consent. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant Contact List Hygiene: make completion observable

Close contact list hygiene with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant Contact List Hygiene: protect the record

Protect contact list hygiene with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant Contact List Hygiene: ask before closing

Before contact list hygiene changes hands, check identity, source date, duplicate status, and consent and leave merged people, stale preferences, and unsafe exports visible where they affect the decision. ### Owner inputs for contact list hygiene

Supply identity, source date, duplicate status, and consent.

**Identity** belongs in the contact list hygiene brief because it changes what the reviewer can confirm.

**Source date** belongs in the contact list hygiene brief because it changes what the reviewer can confirm.

**Duplicate status** belongs in the contact list hygiene brief because it changes what the reviewer can confirm.

**And consent** belongs in the contact list hygiene brief because it changes what the reviewer can confirm.

### Owner decisions
Keep approvals, policy interpretation, and irreversible changes with the responsible owner.

Watch merged people in contact list hygiene; if it appears, preserve the evidence and ask for the named decision.

Watch stale preferences in contact list hygiene; if it appears, preserve the evidence and ask for the named decision.

Watch and unsafe exports in contact list hygiene; if it appears, preserve the evidence and ask for the named decision.

If identity is absent, contact list hygiene should pause before the record is treated as complete.

Use source date to distinguish a standard case from an exception in contact list hygiene.

Check duplicate status against the source before a reviewer accepts contact list hygiene.

Keep and consent beside the handoff when contact list hygiene crosses to another person.

An owner can resolve merged people faster when contact list hygiene preserves the original evidence.

Do not hide stale preferences behind a clean status in a contact list hygiene report.

Route and unsafe exports with a named question rather than a guess about contact list hygiene.

Later review of contact list hygiene should be able to reconstruct why identity was accepted.

For contact list hygiene, a correction is complete only after source date has an observable result.

The owner’s rule for contact list hygiene should say what happens when duplicate status and and consent disagree.
