## Write the exception path first

In the virtual assistant placement and managed services workflow, if a message does not fit a lane, park it in a named intake lane and route one question to the owner; do not create a private side thread. At Best Virtual Assistant Services, use a small code set: missing source, conflicting source, wrong period, identity mismatch, stale approval, system failure. The codes make the queue filterable and show whether the problem is volume, training, access, or a rule that no longer fits.
