# Virtual Assistant Document Naming Standards That Prevent Rework

Virtual Assistant Document Naming Standards That Prevent Rework explains how to delegate document naming standard while keeping the owner’s decisions visible.

## Virtual Assistant Document Naming Standards That Prevent Rework: start with the source

document naming standard starts with document purpose, version marker, date, and storage place. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant Document Naming Standards That Prevent Rework: notice the real risks

document naming standard has a different risk profile: lookalike files, misleading dates, and a current copy that cannot be found. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant Document Naming Standards That Prevent Rework: write a bounded request

Write a bounded request for document naming standard around document purpose, version marker, date, and storage place. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant Document Naming Standards That Prevent Rework: preserve disagreements

If document naming standard produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant Document Naming Standards That Prevent Rework: keep authority clear

For document naming standard, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant Document Naming Standards That Prevent Rework: show the exception

Build a normal example and a pause example from document purpose, version marker, date, and storage place. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant Document Naming Standards That Prevent Rework: make completion observable

Close document naming standard with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant Document Naming Standards That Prevent Rework: protect the record

Protect document naming standard with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant Document Naming Standards That Prevent Rework: ask before closing

Before document naming standard changes hands, check document purpose, version marker, date, and storage place and leave lookalike files, misleading dates, and a current copy that cannot be found visible where they affect the decision.
