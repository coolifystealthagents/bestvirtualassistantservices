# Virtual Assistant Document Naming Standards

For document naming standards, begin with the record that makes the next decision possible, then keep the owner and stopping point visible.

## Virtual Assistant Document Naming Standards: Name for the next reader

A document name should reveal subject, context, date, and status without requiring a file to be opened. Choose the smallest set of fields that distinguishes one document from another. A useful convention serves the person searching six months later, not only the person saving the file today.

## Choose stable fields

Use an unchanging client or project label, a precise subject, and an ISO-style date where dates matter. Keep status words controlled: draft, review, approved, or archived. Avoid vague labels such as final-final or latest, which describe a moment of confidence rather than the record’s state.

## Keep dates honest

Use the date the content represents, not automatically the download date. If both matter, include one in the name and keep the other in metadata. Never alter a historical date just to make a folder sort neatly. Accuracy is more valuable than visual uniformity.

## Plan for search and handoff

Use readable separators, avoid unexplained abbreviations, and keep names within the limits of the storage system. Write the convention in one example-rich page. Test it with a real set of files, including duplicate subjects and a document that changes status.

## Preserve context outside the filename

A filename cannot carry every decision. Pair it with a short description, owner, and retention rule in the document system. The [Library of Congress digital formats guidance](https://www.loc.gov/preservation/digital/formats/fdd/fdd000495.shtml) is a helpful reminder that file identity and preservation context are related but separate concerns.


## Keep the decision visible

For this topic, preserve the source and route uncertainty to the named owner. Reference: [Library of Congress](https://www.loc.gov/preservation/digital/formats/fdd/fdd000495.shtml).
