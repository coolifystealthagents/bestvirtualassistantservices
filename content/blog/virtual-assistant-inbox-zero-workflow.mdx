# Virtual Assistant Inbox Zero Workflow

Good assistant work starts with a specific outcome, a reliable source of truth, and an agreed reviewer. This workflow keeps recurring work easy to assign, inspect, and improve.

## Virtual Assistant Inbox Zero Workflow starts with a written brief

Record the request, required inputs, expected output, tool, timing, definition of done, and stop condition. Add examples of acceptable work and one example that needs revision. Compare the workflow with adjacent roles in the [service role library](/services) before combining unrelated responsibilities.

## Make the handoff visible

Use a short status format that names what is complete, what is waiting, what changed, and what needs approval. Keep source links and decision notes beside the work rather than in private messages. Review early work on a predictable rhythm, then update the brief when the same question appears twice.

## Protect access and escalation boundaries

Give the assistant only the access needed for the assigned lane. Separate preparation from owner decisions, especially where records contain personal, financial, health, or confidential business information. The [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) is a useful baseline for access, passwords, updates, and protecting business information. Use the [provider vetting checklist](/provider-vetting) to ask how screening, training, backup, and quality review are handled.

## Measure the workflow before expanding it

Track completion quality, correction patterns, missed handoffs, review time, and recurring exceptions. A workflow is ready for a broader task lane when instructions are current, access is controlled, evidence is easy to find, and the owner is not repairing the same issue repeatedly.

## Frequently asked questions

### What should a new virtual assistant do first?

Start with one repeatable, low-risk workflow and a small set of approved examples. Expand only after accuracy and review become predictable.

### When should an assistant escalate?

Escalate when required information is missing, the request falls outside the brief, a sensitive decision is involved, or the expected result cannot be verified.

### What makes this workflow useful?

The workflow should make the next action obvious, preserve enough evidence for review, and reduce avoidable back-and-forth without hiding uncertainty.
