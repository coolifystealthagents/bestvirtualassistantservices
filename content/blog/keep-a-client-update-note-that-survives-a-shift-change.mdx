# Keep a client update note that survives a shift change

## How to approach: Keep a client update note that survives a shift change

A client update note should let the next assistant continue without reading every message. Start with the change, the next step, the owner, and the date. A note that says updated the client is not a handoff. Keep the boundary visible in the place where the work is assigned.

Keep the note short and use the same format. The next shift should know what changed and what is still open. Separate what was observed from what was assumed. Record the date and the source so the next reviewer can repeat the check.

## Record the change and the source

Write what changed for the client and the source of the change. A schedule move, a new contact, or a revised scope should be named. A general update hides the detail. Use the same format for every handover so the next reader can scan it.

Record the date and the person who made the change. A later reviewer may need the timeline. Write the deadline as a date and a local time. Review the first few notes together before the process expands.

## Name the next step and the owner

Every open item needs a next action and a named owner. A next step without an owner will be missed. The client should know who is handling the question. A short note with four fields is easier to use than a long narrative.

Record the deadline and the channel. A reply due today should be at the top of the note. Write the deadline as a date and a local time. Ask whether a new reviewer could act on the record without a conversation.

## Protect sensitive detail

Keep sensitive client information in the approved system. Do not copy it into a chat or a personal note. The handoff should point to the record. Separate what was observed from what was assumed.

If a message is ambiguous, pause and ask. A delayed reply is safer than a disclosure. Keep the boundary visible in the place where the work is assigned. Write the deadline as a date and a local time.

## Review the note at handover

Read the last few notes with the next assistant. Ask them to explain the open items. If they cannot, improve the format. A note that cannot be used is not a handoff.
