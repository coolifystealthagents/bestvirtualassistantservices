# Virtual assistant access removal



## How to manage Virtual assistant access removal

List every application, folder, mailbox, saved session, and delegated permission connected to the work. Mark removed, transferred, never granted, or uncertain.

## Role boundary for Virtual assistant access removal

An administrator must revoke permissions and rotate shared secrets; the assistant can assemble evidence and flag gaps.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [CISA account security guidance](https://www.cisa.gov/secure-our-world/use-strong-passwords).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
