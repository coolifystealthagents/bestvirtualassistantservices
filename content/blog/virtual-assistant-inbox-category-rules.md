# Virtual Assistant Inbox Category Rules

Inbox categories work when each one predicts a useful next action. They fail when they merely describe a topic and leave the reviewer to decide what should happen next.

## Virtual Assistant Inbox Category Rules: name the action

Prefer categories such as reply needed, owner decision, waiting for information, and reference. Each category should have a short definition and one example that clarifies its boundary.

## Keep categories mutually useful

If one message fits four categories, simplify the rule or add a priority field. Do not create a new label for every sender. The goal is a reliable view of work, not a complete taxonomy of the mailbox.

## Record exceptions

Messages involving commitments, sensitive information, or unclear authority should move to a named reviewer. A virtual assistant can prepare context and proposed routing but should not invent a response or commitment.

## Test the rules with real samples

Review a small mixed set and note where two people would classify the same message differently. The [email queue prioritization guide](/blog/virtual-assistant-email-queue-prioritization) supports ordering, while the [inbox delegation guide](/blog/virtual-assistant-inbox-delegation-rules) covers ownership.

## Protect the mailbox

Keep access narrow and review shared-mailbox permissions periodically. [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) provides relevant security principles. Clear categories should never require broad access to unrelated information.
