# Virtual assistant file migration controls



## How to manage Virtual assistant file migration controls

Record source path, destination, owner, version, permissions, and dependent links before moving files. Duplicate review must remain separate from deletion.

## Role boundary for Virtual assistant file migration controls

Open representative files and test intended access before the owner accepts the destination; keep the source available until then.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [Library of Congress digital preservation guidance](https://www.loc.gov/preservation/digital/).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
