# Virtual Assistant Project Status Summaries

The best status summary answers four questions: what changed, what is on track, what is at risk, and what decision is needed. It gives the owner a useful signal without pretending that a list of completed tasks is a forecast.

## Virtual Assistant Project Status Summaries: lead with change

Start with the meaningful change since the last update. Mention a completed milestone, a new dependency, or a decision that altered the path. Routine activity can follow in supporting detail.

## Separate progress from confidence

A task can be complete while the overall outcome remains uncertain. Record evidence for progress and name the assumption behind any forecast. This keeps optimism from hiding a real dependency.

## Make risks actionable

For each risk, state its trigger, likely effect, owner, and next review point. The [project status reporting guide](/blog/virtual-assistant-project-status-reporting) helps with presentation, while the [risk register guide](/blog/virtual-assistant-project-risk-register) supports deeper tracking.

## Keep decisions visible

Put owner decisions in a separate section and state the date by which they matter. Do not bury a blocking question in a paragraph of background.

## Use responsible records

Link to the source record and restrict unnecessary detail. [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) is a useful reference for protecting shared project information.
