# Virtual assistant customer data request triage

Separate request scope, identity, source, deadline, and verification state. The assistant can locate records and flag missing proof; the authorized owner decides disclosure or correction.

## Applying virtual assistant customer data request triage

For virtual assistant customer data request triage, begin with the authoritative source and write down the known facts, missing inputs, and due point. Test one ordinary case and one exception before calling the process routine. Keep an unresolved item visible instead of turning an assumption into completion.

## Role boundary and review

In virtual assistant customer data request triage, the virtual assistant may gather context, normalize records, identify gaps, and prepare a review queue. The owner retains decisions involving commitments, sensitive information, public statements, legal interpretation, or irreversible changes. A usable handoff names the evidence, open question, next owner, and review date.
