# Virtual assistant customer data request triage



## How to manage Virtual assistant customer data request triage

Capture requester, account scope, requested fields, and verification evidence. Familiar contact details are not a substitute for an approved identity check.

## Role boundary for Virtual assistant customer data request triage

Use explicit states such as needs verification and ready for review; the privacy owner decides disclosure and redaction.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [ICO right of access guidance](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/individual-rights/right-of-access/).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
