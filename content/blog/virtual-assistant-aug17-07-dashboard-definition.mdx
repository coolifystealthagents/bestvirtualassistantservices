# Virtual assistant dashboard definitions

Define the object counted, inclusion rule, window, source, owner, and exclusions before choosing a chart. Reconcile a sample and show refresh date so completed has a stable meaning.

## Applying virtual assistant dashboard definitions

A dashboard starts with a measurement definition, not a chart. Write the unit, inclusion rule, time window, source fields, refresh owner, and known exclusions before choosing a visual. Reconcile a small sample by hand so a pleasing total does not hide duplicate or stale records.

## Role boundary and review

The assistant can document field mappings, test refreshes, and flag unexplained changes. The owner chooses the business definition and decides whether a gap blocks reporting. Keep the definition beside the dashboard and date revisions when the source or population changes.
