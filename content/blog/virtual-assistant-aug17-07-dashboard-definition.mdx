# Virtual assistant dashboard definitions



## How to manage Virtual assistant dashboard definitions

Write the metric formula, source, time window, owner, and exclusions before updating a dashboard. Average elapsed hours and median business hours answer different questions.

## Role boundary for Virtual assistant dashboard definitions

The assistant can reconcile inputs; the metric owner interprets movement and records limitations beside the number.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [U.S. Census statistical quality standards](https://www.census.gov/about/policies/quality/standards.html).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
