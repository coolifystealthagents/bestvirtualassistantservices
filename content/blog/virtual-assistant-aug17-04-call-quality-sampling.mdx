# Virtual assistant call quality sampling

Define observable criteria for context checks, accuracy, notes, escalation, and close. Sample ordinary, complex, and escalated calls and link every score to an observed moment.

## Applying virtual assistant call quality sampling

For virtual assistant call quality sampling, begin with the authoritative source and write down the known facts, missing inputs, and due point. Test one ordinary case and one exception before calling the process routine. Keep an unresolved item visible instead of turning an assumption into completion.
