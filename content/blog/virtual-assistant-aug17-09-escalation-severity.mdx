# Virtual assistant escalation severity



## How to manage Virtual assistant escalation severity

Define routine, urgent, sensitive, and business-stopping examples with notification path, response window, owner, and evidence.

## Role boundary for Virtual assistant escalation severity

Review misclassified cases and improve examples; do not inflate every request to urgent.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [FEMA incident management guidance](https://www.fema.gov/emergency-managers/nims).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
