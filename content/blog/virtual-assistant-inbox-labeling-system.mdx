# Virtual Assistant Inbox Labeling Systems

For inbox labeling systems, begin with the record that makes the next decision possible, then keep the owner and stopping point visible.

## Virtual Assistant Inbox Labeling Systems: Label for the decision ahead

An inbox label should tell the next reader what kind of attention a message needs: reply, review, waiting, reference, or discard. Labels based on vague feelings create clutter. Choose categories that correspond to an action or a meaningful state.

## Keep the set small

Start with a handful of labels and test them against a week of real messages. If two labels produce the same decision, combine them. Add a category only when the existing set cannot describe an important difference. A small vocabulary is easier to remember and more consistently applied.

## Separate ownership from subject

A label such as waiting-on-client answers a different question from a label such as project-alpha. Keep those dimensions separate if the mail system supports it; otherwise prefer the dimension that changes the next action. This reduces the temptation to create a new label for every topic.

## Treat rules as suggestions

Automatic labels can save time, but they should not silently hide unusual mail. Review rules when senders, projects, or responsibilities change. Keep an eye on false matches, especially for messages involving money, privacy, or a deadline.

## Review the queue by age

A weekly scan should surface old waiting messages, unanswered requests, and labels no longer in use. Archive or delete according to policy, and preserve messages that document a decision. ## Keep the decision visible

For this topic, preserve the source and route uncertainty to the named owner.
