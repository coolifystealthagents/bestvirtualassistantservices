# Virtual Assistant Expense Report Preparation

Published August 31, 2026.

An assistant can prepare expense records while approval, accounting judgment, and reimbursement decisions stay with authorized owners.

## Virtual Assistant Expense Report Preparation: set expense report rules

Document accepted receipt formats, required fields, coding references, submission dates, and the approver. Review adjacent administrative lanes in the [service role library](/services).

## Check completeness and duplicates

Match each line to evidence, flag missing receipts, and search for duplicate date-amount combinations. Never fabricate a category or alter source evidence.

## Keep approvals owner-only

Route exceptions and uncertain classifications to the designated reviewer. Use named accounts and limit access to the records required for the task, following the [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber).

## Archive the approved packet

Store the final report, approval evidence, and exception notes according to retention rules. The [provider vetting checklist](/provider-vetting) helps buyers ask about access and review practices.

## Frequently asked questions

### What should the assistant document?

Document the source, action, status, owner, due date, and any exception that needs review.

### When should work stop?

Stop when evidence is missing, instructions conflict, access is inappropriate, or an owner-only decision is required.
