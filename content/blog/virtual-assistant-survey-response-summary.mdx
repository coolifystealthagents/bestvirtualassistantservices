# Virtual Assistant Survey Response Summary

Virtual Assistant Survey Response Summary explains how to delegate survey response summary while keeping the owner’s decisions visible.

## Virtual Assistant Survey Response Summary: start with the source

survey response summary starts with response count, question wording, theme, outlier, and limitation. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant Survey Response Summary: notice the real risks

survey response summary has a different risk profile: averages that hide minority views and summaries that overstate certainty. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant Survey Response Summary: write a bounded request

Write a bounded request for survey response summary around response count, question wording, theme, outlier, and limitation. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant Survey Response Summary: preserve disagreements

If survey response summary produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant Survey Response Summary: keep authority clear

For survey response summary, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant Survey Response Summary: show the exception

Build a normal example and a pause example from response count, question wording, theme, outlier, and limitation. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant Survey Response Summary: make completion observable

Close survey response summary with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant Survey Response Summary: protect the record

Protect survey response summary with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant Survey Response Summary: ask before closing

Before survey response summary changes hands, check response count, question wording, theme, outlier, and limitation and leave averages that hide minority views and summaries that overstate certainty visible where they affect the decision. ### Owner inputs for survey response summary

Supply response count, question wording, theme, outlier, and limitation.

**Response count** belongs in the survey response summary brief because it changes what the reviewer can confirm.

**Question wording** belongs in the survey response summary brief because it changes what the reviewer can confirm.

**Theme** belongs in the survey response summary brief because it changes what the reviewer can confirm.

**Outlier** belongs in the survey response summary brief because it changes what the reviewer can confirm.

**And limitation** belongs in the survey response summary brief because it changes what the reviewer can confirm.

### Owner decisions
Keep approvals, policy interpretation, and irreversible changes with the responsible owner.

Watch averages that hide minority views and summaries that overstate certainty in survey response summary; if it appears, preserve the evidence and ask for the named decision.

If response count is absent, survey response summary should pause before the record is treated as complete.

Use question wording to distinguish a standard case from an exception in survey response summary.

Check theme against the source before a reviewer accepts survey response summary.

Keep outlier beside the handoff when survey response summary crosses to another person.

An owner can resolve averages that hide minority views and summaries that overstate certainty faster when survey response summary preserves the original evidence.

Do not hide averages that hide minority views and summaries that overstate certainty behind a clean status in a survey response summary report.

Route averages that hide minority views and summaries that overstate certainty with a named question rather than a guess about survey response summary.

Later review of survey response summary should be able to reconstruct why response count was accepted.

For survey response summary, a correction is complete only after question wording has an observable result.

The owner’s rule for survey response summary should say what happens when theme and outlier disagree.
