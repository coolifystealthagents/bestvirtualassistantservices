## Write the exception path first

At Best Virtual Assistant Services, if the owner is unavailable, record the temporary decision and its expiry; do not let an interim choice become permanent by silence. Every exception needs a reason code, a next owner, a recheck date, and the action the specialist must not take.

At Best Virtual Assistant Services, use a small code set: missing source, conflicting source, wrong period, identity mismatch, stale approval, system failure. The codes make the queue filterable and show whether the problem is volume, training, access, or a rule that no longer fits.
