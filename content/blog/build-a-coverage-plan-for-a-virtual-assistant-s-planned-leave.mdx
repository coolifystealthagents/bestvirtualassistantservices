# Build a coverage plan for a virtual assistant's planned leave

## How to approach: Build a coverage plan for a virtual assistant's planned leave

A coverage plan should start with the work that cannot wait. Name the tasks, the backup, the access, and the handover date. A plan that names only a backup person is not coverage. Ask whether a new reviewer could act on the record without a conversation.

Keep the plan short enough to test before the leave. The backup should be able to start without a meeting. A control that depends on memory is not yet a control. Record the date and the source so the next reviewer can repeat the check.

## List the must-continue tasks

Record the tasks with a client deadline, a payment, or a compliance requirement. Mark the tasks that can pause. A backup who tries to do everything will do the important work poorly. Record the exception and the person who approved it.

Name the owner and the next date for each task. A task without an owner will be missed. A control that depends on memory is not yet a control. Keep the evidence with the record rather than in a separate log.

## Confirm the access and the handover

Check that the backup can open the systems and the files. Test the access before the leave. Record any pending approval and the person who owns it. Record the date and the source so the next reviewer can repeat the check.

Set the handover date and the channel. The handover should include the open tasks, the contacts, and the decisions that must wait. If the source is unclear, route the question instead of guessing. Write the deadline as a date and a local time.

## Set the decision boundary

State what the backup may decide and what must wait for the manager. A routine reschedule may be fine, while a client commitment is not. Name the owner in the same line as the action. Ask whether a new reviewer could act on the record without a conversation.

Record the boundary in the handover note. A boundary that lives only in a policy file will be missed. Update the template when the same question appears twice. If the source is unclear, route the question instead of guessing.

## Review the plan after the leave

Review what worked and what caused stress. Update the task list, the access, and the handover. A plan that improves after each absence is more useful than a perfect template. Record the date and the source so the next reviewer can repeat the check.
