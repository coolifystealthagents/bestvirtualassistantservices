# Virtual Assistant Spreadsheet Review Queues

Large spreadsheet checks become manageable when each row has a review state and a next action. The queue should expose uncertainty instead of hiding it in a colored cell.

## Virtual Assistant Spreadsheet Review Queues: define the unit

Choose whether one queue item is a row, a record, or a grouped exception. Include a stable identifier so the reviewer can return to the exact source.

## Use states that lead somewhere

Useful states include not started, checking, question open, corrected, and owner review. Define who may move each item to the next state.

## Protect the source

Work from a controlled copy or approved view and record the version checked. The [spreadsheet review guide](/blog/virtual-assistant-spreadsheet-review-rules) helps with checks, and the [data entry controls guide](/blog/virtual-assistant-data-entry-quality-controls) supports accuracy.

## Escalate patterns

If many rows share the same defect, report the pattern and sample evidence. Do not silently change a rule across the sheet without approval.

## Handle sensitive cells carefully

Restrict exports and avoid placing private values in queue titles. Review [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) for access and sharing practices.
