# Virtual assistant time-zone handoffs



## How to manage Virtual assistant time-zone handoffs

Write the governing clock, working window, local deadline, and next escalation contact. “Tomorrow” is unsafe language when a task crosses midnight.

## Role boundary for Virtual assistant time-zone handoffs

A handoff can prepare options after the owner’s day ends, but it cannot create authority to make an urgent decision.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [IANA Time Zone Database](https://www.iana.org/time-zones).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
