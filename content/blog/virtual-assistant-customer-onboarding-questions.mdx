# Customer Onboarding Questions a Virtual Assistant Can Organize

Customer Onboarding Questions a Virtual Assistant Can Organize explains how to delegate customer onboarding questions while keeping the owner’s decisions visible.

## Customer Onboarding Questions a Virtual Assistant Can Organize: start with the source

customer onboarding questions starts with desired outcome, current state, access, and exclusions. Those fields identify the record and the detail that can change the answer.

## Customer Onboarding Questions a Virtual Assistant Can Organize: notice the real risks

customer onboarding questions has a different risk profile: friendly assumptions, unclear scope, and a kickoff with no deliverable. Compare the record with its source instead of filling a gap from memory.

## Customer Onboarding Questions a Virtual Assistant Can Organize: write a bounded request

Write a bounded request for customer onboarding questions around desired outcome, current state, access, and exclusions. Name the result so a person who did not do the work can inspect it.

## Customer Onboarding Questions a Virtual Assistant Can Organize: preserve disagreements

If customer onboarding questions produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Customer Onboarding Questions a Virtual Assistant Can Organize: keep authority clear

For customer onboarding questions, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Customer Onboarding Questions a Virtual Assistant Can Organize: show the exception

Build a normal example and a pause example from desired outcome, current state, access, and exclusions. The pause example records the evidence, uncertainty, and question that travels onward.

## Customer Onboarding Questions a Virtual Assistant Can Organize: make completion observable

Close customer onboarding questions with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Customer Onboarding Questions a Virtual Assistant Can Organize: protect the record

Protect customer onboarding questions with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Customer Onboarding Questions a Virtual Assistant Can Organize: ask before closing

Before customer onboarding questions changes hands, check desired outcome, current state, access, and exclusions and leave friendly assumptions, unclear scope, and a kickoff with no deliverable visible where they affect the decision.
