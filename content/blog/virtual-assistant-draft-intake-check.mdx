# Virtual Assistant Draft Intake Check

Published September 1, 2026.

A draft intake check confirms that an editor received the expected package; it does not replace substantive editing.
Use the [content calendar workflow](/blog/virtual-assistant-content-calendar-workflow) to place this control in the daily sequence, the [editorial quality checklist](/blog/virtual-assistant-editorial-quality-checklist) for adjacent review steps, and [NIST small business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) when the routine handles business information.

## Virtual Assistant Draft Intake Check: operating steps

Verify the working title, audience, intent, required sections, word-range expectation, and call to action. Record mismatches in the handoff instead of silently rewriting the assignment.

## Confirm the evidence package travels with it

Open source links, locate citations or claim notes, and identify any fact marked for verification. If a key source is inaccessible, return the package before it occupies an editorial slot.

## Test basic document hygiene

Check heading order, placeholder text, broken internal links, comments, and file permissions. These mechanical checks are suitable for a virtual assistant because pass and fail conditions can be written clearly.

## Route rather than judge

Send incomplete packages back to the drafter with a precise list. Send complete packages to the editor without declaring the article accurate, persuasive, or ready to publish.

## Frequently asked questions

### Is this a copyedit?

No. Intake checks completeness and accessibility; copyediting evaluates language, consistency, and editorial standards.

### What evidence should be retained?

Keep the checklist result, return reason if any, timestamps, and the version delivered to editorial review.
