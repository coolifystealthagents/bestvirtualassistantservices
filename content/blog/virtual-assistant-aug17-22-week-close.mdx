# Virtual assistant week-close reviews



## How to manage Virtual assistant week-close reviews

A week-close should distinguish completed work, carried work, blocked inputs, quality exceptions, and owner decisions. Tie each line to an evidence source.

## Role boundary for Virtual assistant week-close reviews

For every carried item, record next action, due date, dependency, and reason it remains active. A status that never changes is not a close.

## Evidence and handoff

Use the [services library](/services) and [provider vetting](/provider-vetting) to define ownership. For a named reference, consult [PMI project management standards](https://www.pmi.org/standards).

## FAQ

### What should the owner record?
The source, reviewer, next action, and the point at which the virtual assistant must stop and escalate.
