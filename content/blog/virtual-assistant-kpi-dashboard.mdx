# Virtual Assistant KPI Dashboard: What to Track by Role

A role-based guide to choosing a small set of useful measures for administrative, support, sales, and operations assistance.

## Virtual Assistant KPI Dashboard: What to Track by Role: A KPI dashboard should explain the work, not create busywork

Choose measures that reflect the result the owner needs: accurate records, answered requests, completed follow-ups, clean calendars, or ready-to-review documents. Start with three to five measures and define the source, period, owner, and acceptable exception. A dashboard is useful when it leads to a decision, not when it merely contains many numbers.

## Match measures to the role

For inbox support, track items sorted, response drafts accepted, and unresolved escalations. For CRM support, track records updated, missing fields found, and duplicate entries prevented. For calendar support, track conflicts resolved and changes awaiting approval. Pair every count with a quality sample so speed cannot hide rework. The CRM data-entry checklist shows how to make a measure traceable.

## Turn trends into coaching questions

A falling completion count may reflect a harder queue, missing information, or a new approval rule. Ask what changed before judging performance. Review one strong example and one exception each week, then adjust the brief or access boundary. Use NIST small-business guidance when dashboard records include sensitive data: [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber)

## Frequently asked questions

### What should the owner provide first?

Provide the source of truth, approved examples, the expected output, the reviewer, and a clear rule for exceptions.

### What should remain with the owner?

Keep approvals, policy interpretation, sensitive decisions, and irreversible changes with the responsible owner.
