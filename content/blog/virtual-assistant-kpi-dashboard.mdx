# Virtual Assistant KPI Dashboard: What to Track by Role

Virtual Assistant KPI Dashboard: What to Track by Role explains how to delegate kpi dashboard while keeping the owner’s decisions visible.

## Virtual Assistant KPI Dashboard: What to Track by Role: start with the source

kpi dashboard starts with metric definition, formula, source field, and reporting period. Those fields identify the record and the detail that can change the answer.

## Virtual Assistant KPI Dashboard: What to Track by Role: notice the real risks

kpi dashboard has a different risk profile: changed denominators, partial data, and attractive numbers with no meaning. Compare the record with its source instead of filling a gap from memory.

## Virtual Assistant KPI Dashboard: What to Track by Role: write a bounded request

Write a bounded request for kpi dashboard around metric definition, formula, source field, and reporting period. Name the result so a person who did not do the work can inspect it.

## Virtual Assistant KPI Dashboard: What to Track by Role: preserve disagreements

If kpi dashboard produces disagreement, retain both entries and identify the decision owner. Mark any proposed correction as proposed.

## Virtual Assistant KPI Dashboard: What to Track by Role: keep authority clear

For kpi dashboard, written authority may cover sorting, drafting, checking, and flagging. Sensitive approval and irreversible change remain owner decisions.

## Virtual Assistant KPI Dashboard: What to Track by Role: show the exception

Build a normal example and a pause example from metric definition, formula, source field, and reporting period. The pause example records the evidence, uncertainty, and question that travels onward.

## Virtual Assistant KPI Dashboard: What to Track by Role: make completion observable

Close kpi dashboard with its source, change, unresolved item, and next action. A generic status cannot show whether review is still waiting.

## Virtual Assistant KPI Dashboard: What to Track by Role: protect the record

Protect kpi dashboard with the smallest necessary record. The [NIST small-business cybersecurity guidance](https://www.nist.gov/itl/smallbusinesscyber) gives a useful baseline.

## Virtual Assistant KPI Dashboard: What to Track by Role: ask before closing

Before kpi dashboard changes hands, check metric definition, formula, source field, and reporting period and leave changed denominators, partial data, and attractive numbers with no meaning visible where they affect the decision. See the [virtual assistant delegation guide](/blog/virtual-assistant-delegation-readiness) and [document review process](/blog/virtual-assistant-document-review-process).

### Owner inputs for kpi dashboard

Supply metric definition, formula, source field, and reporting period.

**Metric definition** belongs in the kpi dashboard brief because it changes what the reviewer can confirm.

**Formula** belongs in the kpi dashboard brief because it changes what the reviewer can confirm.

**Source field** belongs in the kpi dashboard brief because it changes what the reviewer can confirm.

**And reporting period** belongs in the kpi dashboard brief because it changes what the reviewer can confirm.

### Owner decisions
Keep approvals, policy interpretation, and irreversible changes with the responsible owner.

Watch changed denominators in kpi dashboard; if it appears, preserve the evidence and ask for the named decision.

Watch partial data in kpi dashboard; if it appears, preserve the evidence and ask for the named decision.

Watch and attractive numbers with no meaning in kpi dashboard; if it appears, preserve the evidence and ask for the named decision.

If metric definition is absent, kpi dashboard should pause before the record is treated as complete.

Use formula to distinguish a standard case from an exception in kpi dashboard.

Check source field against the source before a reviewer accepts kpi dashboard.

Keep and reporting period beside the handoff when kpi dashboard crosses to another person.

An owner can resolve changed denominators faster when kpi dashboard preserves the original evidence.

Do not hide partial data behind a clean status in a kpi dashboard report.

Route and attractive numbers with no meaning with a named question rather than a guess about kpi dashboard.

Later review of kpi dashboard should be able to reconstruct why metric definition was accepted.

For kpi dashboard, a correction is complete only after formula has an observable result.
