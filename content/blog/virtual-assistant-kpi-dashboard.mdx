# Virtual Assistant KPI Dashboard Preparation

For kpi dashboard preparation, begin with the record that makes the next decision possible, then keep the owner and stopping point visible.

## Virtual Assistant KPI Dashboard Preparation: Choose a decision before a metric

A dashboard earns its place by helping someone decide what to continue, investigate, or change. Write the decision beside each proposed measure. If no decision follows a number, it may belong in a report or source table rather than the main view.

## Define each measure in plain language

For every KPI, state the numerator, denominator, time window, source, owner, and refresh expectation. Explain what an increase or decrease means. A familiar label such as conversion or response time can hide several legitimate definitions, so the definition belongs next to the chart.

## Protect comparability

Use the same population and time boundaries when comparing periods. Mark partial periods, changed definitions, exclusions, and missing data. Do not make a smooth line by silently replacing a gap. Honest context is more useful than false precision.

## Make the first screen calm

Lead with a small set of measures tied to the current decision. Put diagnostic detail behind a clear path. Use annotations for major changes, launches, outages, or policy shifts so a reader does not mistake an event for an underlying trend.

## Review the dashboard as a product

Ask whether the intended reader can find the answer, interpret it, and name the next action. Retire metrics no one uses and document changes to the definition. The [GAO performance measurement guide](https://www.gao.gov/products/gao-20-701g) is a strong reference for linking measures to management decisions.


## Keep the decision visible

For this topic, preserve the source and route uncertainty to the named owner. Reference: [U.S. Government Accountability Office](https://www.gao.gov/products/gao-20-701g).
